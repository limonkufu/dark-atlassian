# Catppuccin Mocha for SKAO Atlassian

A Chrome extension (Manifest V3) that themes **confluence.skatelescope.org** and
**jira.skatelescope.org** with the [Catppuccin Mocha](https://catppuccin.com) palette.
It works while browsing and while editing (Confluence editor, Jira dialogs, comment
editors, boards, dashboards), and it can switch itself on only at night.

## Install (unpacked)

1. Open `chrome://extensions` and switch on **Developer mode** (top right).
2. Click **Load unpacked** and pick this folder (`dark-atlassian`).
3. Pin the extension and click its icon to choose a mode.

Reload the extension from `chrome://extensions` after editing any file; open tabs pick up
new CSS on their next page load.

## Modes (popup)

| Mode | Behaviour |
| --- | --- |
| Scheduled (default) | Dark between **From** and **To** (default 19:00 to 07:00, local time, wraps midnight). |
| Always on | Dark all the time. |
| Always off | Never themed. |
| Follow system | Follows the OS dark-mode setting. |

- **Apply to** lets you disable either site.
- In Scheduled / System mode the popup offers a temporary **Turn on/off until …**
  override that expires at the next scheduled change (or midnight).
- **Alt+Shift+M** does the same toggle from the keyboard (change it at `chrome://extensions/shortcuts`).
- The toolbar badge shows `ON`, `OFF` or `SYS`.

Switching happens live in open tabs, without a reload.

## How it themes the page

Three layers, strongest first:

1. `styles/tokens.css`, `styles/aui.css`, `styles/confluence.css` / `styles/jira.css`
   Hand-written Catppuccin rules. Atlassian's own design tokens (`--aui-*` and `--ds-*`)
   and the Rich Filters gadget palette (`--qoti-*`) are overridden at the root, which
   themes most AUI components and filter gadgets in one go, plus explicit
   rules for Confluence 8.x / Jira 9.x chrome: header, sidebars, page tree, tables, cell
   highlights, macros, code blocks, comments, the TinyMCE editor body, Jira issue view,
   navigator, boards/backlog, dialogs, inline edit, wiki / rich-text editors, dashboards.
2. **Dynamic layer** (`src/content.js`): every page stylesheet is scanned and light
   backgrounds, dark text and light borders are rewritten to dark equivalents in a
   generated stylesheet. This covers plugins and pages the hand-written CSS doesn't know.
3. **Inline layer**: `style=""` colours are matched with generated `[style="…"]` rules.
   Page content is never modified, so it is safe inside editors (the editor body is what
   gets saved).

Everything is scoped under `html[data-ctp-mocha]`; removing the attribute restores the
light theme instantly. The last known state and the CSS are cached in `localStorage` so
pages come up dark without a light flash.

Same-origin iframes (the Confluence editor body, Jira gadgets) are themed by their own
copy of the content script, which marks the frame's `<html>` with `data-ctp-frame`. The
parent frame only themes iframes without that mark, so each document is processed once.

## Files

```
manifest.json          MV3 manifest
src/schedule.js        shared schedule / mode logic
src/background.js      badge, alarms at the next scheduled change, keyboard shortcut
src/content.js         theme injection + dynamic + inline layers
styles/*.css           the theme
popup/                 settings popup
icons/                 generated by scripts/make_icons.py
scripts/dev-server.py  dev only: serves this folder with CORS for the test harness
scripts/test-harness.js dev only: runs the content script on a live page with chrome.* stubbed
```

## Adding another Atlassian host

Add the host to `matches`, `host_permissions` and `web_accessible_resources[].matches`
in `manifest.json`, and make `siteOf()` in `src/schedule.js` return `confluence` or
`jira` for it.
